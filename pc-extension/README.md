# Cloud Chrome 로그인 보내기 (PC 크롬 확장)

PC 크롬에 로그인돼 있는 상태(쿠키)를 읽어 클라우드 크롬으로 보냅니다. 클라우드 크롬이 막던 구글·네이버 등 로그인을, PC에서 이미 로그인한 것을 그대로 옮겨 해결하는 방식입니다.

## 설치 (한 번만)

1. 크롬 주소창에 `chrome://extensions` 입력 → 엔터
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 이 `pc-extension` 폴더 선택
4. 툴바에 생긴 확장 아이콘(퍼즐 모양 안)을 클릭

## 사용

1. 팝업에서 **클라우드 크롬 주소**(예: `https://cloud-chrome-assist.vercel.app`)와 **연결 키(ASSIST_KEY)** 입력 → **설정 저장**
2. 보낼 사이트를 정하려면 **보낼 사이트** 칸에 `naver.com, daum.net` 처럼 입력(비우면 전부).
   - 지금 보는 사이트만 보내려면 **이 사이트만** 버튼을 누르세요.
3. **로그인 보내기** 클릭 → ✅ 메시지가 뜨면 클라우드 크롬에 로그인이 옮겨진 것입니다.

보낸 쿠키는 클라우드 크롬에 저장되어 크롬이 다시 켜져도 유지됩니다.

## 참고

- 연결 키는 PC의 이 확장에만 저장되며, 전송은 HTTPS로만 이뤄집니다.
- 구글 계정은 접속 위치(IP)가 바뀌면 다시 본인 확인을 요구할 수 있습니다. 네이버·다음·카카오 등 대부분 사이트는 쿠키만으로 바로 로그인됩니다.
- 로그인이 풀리면 PC에서 다시 로그인한 뒤 **로그인 보내기**를 한 번 더 누르면 됩니다.
